# Workspace Development Guidelines

## Browser Testing & Debugging
- Whenever debugging, implementing frontend features, or testing web pages/APIs, **default to using Chrome DevTools (chrome-devtools-mcp / browser automation tools)** to inspect the live application.
- Use DevTools to verify:
  1. **Visual UI & UX**: Take screenshots to ensure layouts, modals, buttons, and zero-scroll states render accurately.
  2. **Console Logs & Errors**: Inspect runtime JavaScript errors and warnings.
  3. **Network Requests**: Monitor API calls, payloads, and response statuses.
  4. **DOM & CSS State**: Validate interactive elements, focus states, and responsive behavior.
